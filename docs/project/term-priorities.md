# 用語集の追加候補優先順位

## 方針

初回公開では、`配信で頻出する` かつ `他ページの前提になる` 用語を先に掲載する。  
そのうえで、公開後に追加しやすい用語を優先順位つきで整理しておく。

## 優先度A

- ファーム
- スノーボール
- キャリー
- ピール
- フラッシュ

## 優先度B

- ウェーブ
- プッシュ
- フリーズ
- バックライン
- フロントライン

## 優先度C

- バースト
- DPS
- スケール
- パワースパイク
- ゾーニング

## 補足

- 優先度Aは、実況や配信で比較的そのまま聞こえやすい言葉を並べている。
- 優先度Bは、レーン戦や集団戦の理解を一段深める用語である。
- 優先度Cは、チャンピオン個別ページやアイテム入門と一緒に増やすと分かりやすい。
