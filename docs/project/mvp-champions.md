# LoL Viewer Wiki MVP掲載チャンピオン候補

## 1. 文書の目的

本書は、`LoL Viewer Wiki` の MVP で個別ページを作成するチャンピオンを明確にするための管理用文書である。  
初回公開では、全チャンピオンを詳細掲載するのではなく、`観戦初心者が役割の違いを理解しやすい代表例` として各レーン 2 体ずつ選定する。

## 2. 選定方針

- 現在の一時的なメタではなく、長期的に見て観戦で登場しやすいチャンピオンを優先する
- 各レーンの役割差が説明しやすい組み合わせにする
- 初心者が見た目や役割を覚えやすいチャンピオンを優先する
- チャンピオン個別ページのテンプレート検証にも向く題材を選ぶ

### Support

- スレッシュ
- ノーチラス

## 4. この 10 体を選ぶ理由

- Top:
  - `レネクトン` は前に出て主導権を握るファイターの説明に向く
  - `オーン` は集団戦や前線形成を担うタンクの説明に向く
- Jungle:
  - `リー・シン` は序盤の仕掛けや機動力の説明に向く
  - `ジャーヴァンⅣ` はガンク、エンゲージ、集団戦開始の説明に向く
- Mid:
  - `オリアナ` は集団戦コントロール系メイジの説明に向く
  - `アーリ` は機動力、ピック、ロームの説明に向く
- ADC:
  - `ジン` は射程管理やスキル主体のマークスマンの説明に向く
  - `カイ＝サ` は後入りや追撃、柔軟な戦い方の説明に向く
- Support:
  - `スレッシュ` はプレイメイク系サポートの説明に向く
  - `ノーチラス` は分かりやすいエンゲージ系サポートの説明に向く

## 5. 運用ルール

- MVP 実装時は、この 10 体を個別ページの初期対象とする
- 余力がある場合のみ、MVP 公開前に追加候補を検討する
- MVP 公開後に掲載対象を増やす場合も、まずは各レーンの説明バランスを崩さないことを優先する
