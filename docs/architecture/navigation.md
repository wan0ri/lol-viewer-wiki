# LoL Viewer Wiki 導線設計メモ

## 1. 文書の目的

本書は、`LoL Viewer Wiki` の情報導線を整理するための設計メモである。  
本サイトは一般的な網羅型 Wiki ではなく、`LoL をあまり知らない観戦者が、迷わず必要な情報にたどり着けること` を重視する。

## 2. 導線設計の基本方針

### 2.1 方針

- カテゴリ名よりも、`ユーザーの悩み` から導線を作る
- 初心者向けページは、単発閲覧ではなく `順番に読める構成` にする
- 用語集やチャンピオンページは、`辞書として探しやすいこと` を優先する
- 各ページから次に読むべきページを明示する
- 回遊を増やすために、関連ページへの導線を統一する

### 2.2 このサイトで解決したい主な悩み

- LoL がどんなゲームか分からない
- 配信で何が起きているのか分からない
- 用語が分からない
- チャンピオンが何をするキャラか分からない
- パッチ変更を読んでも意味が分からない

### 2.3 導線の考え方

本サイトの導線は、次の 3 種類に分けて設計する。

1. 入口導線
2. 学習導線
3. 辞書導線

#### 入口導線

トップページで、ユーザーが今の悩みに応じて最初の入口を選べるようにする。

#### 学習導線

初心者向けページ群では、全体像から順に理解できるよう、読む順番を示す。

#### 辞書導線

用語、ロール、チャンピオン、オブジェクトなどは、個別に調べた後も関連ページへ移動しやすくする。

チャンピオン一覧ページでは、少なくとも以下の情報を固定表示する。

- 名前
- 画像
- 主なロール
- ひとことで言うと

## 3. 推奨する導線構造

### 3.1 全体像

基本的な流れは以下とする。

1. トップページ
2. はじめて見る人向け
3. ロール / オブジェクト / 用語
4. チャンピオン一覧 / 個別ページ
5. パッチノート要約

### 3.2 初心者向けの学習順

初心者向けページは、以下の順番で読めるようにする。

1. LoLとは何か
2. 勝利条件
3. サモナーズリフトの見方
4. 試合の流れ
5. 観戦するときにまず見るポイント
6. ロール解説
7. オブジェクト解説
8. 用語集
9. チャンピオン一覧

この順番の意図は以下の通り。

- まずゲーム全体を理解する
- 次に試合中に何を見ればよいかを理解する
- その後でロールや用語などの個別知識に進む
- 最後にチャンピオンごとの差を理解する

## 4. トップページ導線案

## 4.1 目的

トップページは、`どこから読めばいいか分からない人` を迷わせないための入口である。  
そのため、カテゴリ名だけを並べるのではなく、`悩みベースの入口` を優先する。

## 4.2 上部で見せる主要導線

トップページのファーストビュー直下では、以下の 4 導線を最優先で出す。

- はじめて見る人はこちら
- 配信で聞く言葉を調べる
- チャンピオンを探す
- 最新パッチをやさしく読む

### 4.3 各導線の遷移先

- `はじめて見る人はこちら`
  - 遷移先: `/start/`
- `配信で聞く言葉を調べる`
  - 遷移先: `/terms/`
- `チャンピオンを探す`
  - 遷移先: `/champions/`
- `最新パッチをやさしく読む`
  - 遷移先: `/patch-notes/latest/`

### 4.4 トップページの推奨構成

1. ヒーローエリア
2. 主要導線 4 つ
3. はじめて見る人向けのおすすめ順
4. 注目コンテンツ
5. チャンピオン導線
6. 最新パッチ導線

### 4.5 ヒーローエリアに入れる内容

- サイトの一言説明
- このサイトで分かること
- 最初に読むべきページへのCTA

例:

- タイトル:
  - `LoL配信を、もう少し分かりやすく。`
- 説明:
  - `League of Legends をあまり知らなくても、配信や大会で何が起きているかを理解しやすくするための観戦ガイドです。`
- CTA:
  - `はじめて見る人はこちら`

### 4.6 はじめて見る人向けのおすすめ順

トップページ上で、初心者に対して次の順序を見せる。

1. LoLとは何か
2. 勝利条件
3. マップの見方
4. 試合の流れ
5. 観戦でまず見るポイント

このブロックは、`何から読めばいいか分からない人向けの学習導線` として機能させる。

### 4.7 注目コンテンツ枠

トップページ中段には、以下のような実用導線を置く。

- よく使われる用語
- 初心者におすすめのチャンピオン紹介
- 最新パッチ要約

パッチ要約については、過去パッチを一覧で大量に並べるのではなく、まずは `その時点で読む価値が高い最新要約` を強く見せる方針とする。

### 4.8 避けたい構成

- カテゴリ一覧だけを並べる
- リンク数が多すぎて最初の行動が決められない
- 初心者向け導線と辞書導線が混ざっている
- 用語、チャンピオン、パッチへの導線を同じ強さで並べすぎる

## 5. グローバルナビゲーション案

グローバルナビゲーションは、常に表示される主要カテゴリとして以下を想定する。

- はじめて見る人向け
- 用語集
- ロール
- オブジェクト
- チャンピオン
- パッチノート

補助的なページはフッターまたは下層導線で扱う。

- このサイトについて
- Riot 非公式表記

## 6. 各ページ末尾の共通UI案

## 6.1 目的

各ページの末尾には、`読了後に次へ進みやすくする導線` を共通で置く。  
これにより、単発のページ閲覧で終わらず、理解に必要な次のページへ自然に移動できるようにする。

### 6.2 共通で置くブロック

ページ末尾には、原則として以下の 3 ブロックを置く。

- 次に読む
- あわせて読む
- 関連用語 / 関連ページ

### 6.3 ブロックの役割

#### 次に読む

- 学習順に従って、`次に読むべき1ページ` を明示する
- 選択肢を増やしすぎない

#### あわせて読む

- 今読んだページと強く関連する 2〜3 ページを置く
- 文脈理解を補助する目的で使う

#### 関連用語 / 関連ページ

- 辞書的に参照しやすいリンク群として置く
- 用語ページ、ロールページ、チャンピオンページとの往復を作る

## 6.4 ページ種別ごとの末尾UI例

### はじめて見る人向けページ

- 次に読む:
  - 学習順で次のページ
- あわせて読む:
  - 今のテーマと関連が強いページ
- 関連用語:
  - 本文中で出た重要用語

例:

- ページ: `勝利条件`
- 次に読む:
  - `サモナーズリフトの見方`
- あわせて読む:
  - `LoLとは何か`
  - `試合の流れ`
- 関連用語:
  - `タワー`
  - `インヒビター`
  - `バロン`

### 用語ページ

- 次に読む:
  - その用語がよく出る文脈ページ
- あわせて読む:
  - 類似用語またはセットで出る用語
- 関連ページ:
  - 関係するロール、オブジェクト、チャンピオン一覧

例:

- ページ: `ガンク`
- 次に読む:
  - `Jungle`
- あわせて読む:
  - `ローム`
  - `レーン戦`
- 関連ページ:
  - `ロール解説`
  - `観戦するときにまず見るポイント`

### ロールページ

- 次に読む:
  - ロール比較ページまたは関連度の高い用語ページ
- あわせて読む:
  - そのロールで頻出する用語
- 関連ページ:
  - 該当ロールの代表チャンピオン一覧

例:

- ページ: `Support`
- 次に読む:
  - `各ロールの役割と見どころ`
- あわせて読む:
  - `視界`
  - `エンゲージ`
  - `集団戦`
- 関連ページ:
  - `チャンピオン一覧`

### オブジェクトページ

- 次に読む:
  - `オブジェクトを取る意味`
- あわせて読む:
  - 関連するオブジェクトページ
- 関連用語:
  - 集団戦、視界、プッシュ など

### チャンピオン個別ページ

- 次に読む:
  - そのチャンピオンが属するロールページ
- あわせて読む:
  - 関連用語 2〜3 件
- 関連ページ:
  - 類似チャンピオン
  - 関連パッチ

例:

- ページ: `Ahri`
- 次に読む:
  - `Mid`
- あわせて読む:
  - `ローム`
  - `バースト`
  - `エンゲージ`
- 関連ページ:
  - `最新パッチ要約`
  - `チャンピオン一覧`

### パッチノート要約ページ

- 次に読む:
  - 最新パッチから関係するチャンピオンページまたは用語ページ
- あわせて読む:
  - 前回パッチまたは関連解説ページ
- 関連ページ:
  - チャンピオン一覧
  - アイテム解説

## 7. 実装時のルール

- `次に読む` は 1 件に絞る
- `あわせて読む` は最大 3 件までにする
- `関連用語 / 関連ページ` は多すぎないようにする
- 1 画面にリンクを詰め込みすぎない
- 導線テキストはカテゴリ名よりも意味が伝わる文にする

## 8. 情報設計フェーズで確定したい項目

フェーズ3では、少なくとも以下を確定対象とする。

- トップページの主要導線
- グローバルナビゲーション
- 初心者向けページの読む順番
- 各ページ種別の末尾UIルール
- 用語、ロール、チャンピオン間の相互リンク方針
