# LoL Viewer Wiki MVP定義

## 1. 目的

本書は、`LoL Viewer Wiki` の初回公開範囲を明確にするための MVP 定義書である。  
最初の公開では、機能やデータ量を広げすぎず、`LoL を見ているが何が起きているか分からない人が、最低限観戦しやすくなること` を達成目標とする。

## 2. MVPに含める範囲

初回公開で含める対象は以下とする。

- はじめて見る人向け
- 用語集
- ロール解説
- オブジェクト解説
- チャンピオン一覧
- 一部チャンピオン詳細
- 最新パッチ要約

## 3. MVPの達成条件

以下を満たした時点で、MVP として公開可能と判断する。

- LoL を知らない人が、試合の基本構造を理解できる
- 配信で頻出する最低限の用語を引ける
- 各ロールの違いを説明できる
- ドラゴンやバロンなど主要オブジェクトの意味を説明できる
- チャンピオン一覧から、最低限「何をするキャラか」を把握できる
- 一部チャンピオンについて、観戦時の見どころと代表的なルーンを確認できる
- 最新パッチについて、初心者向けのやさしい要約を1本読める

## 4. 初回公開時の具体的な掲載範囲

### 4.1 はじめて見る人向け

以下の 5 ページを必須とする。

- LoLとは何か
- 勝利条件
- サモナーズリフトの見方
- 試合の流れ
- 観戦するときにまず見るポイント

### 4.2 用語集

まずは以下の用語を優先掲載対象とする。

- キル、デス、アシスト
- CS
- ゴールド
- レベル
- 集団戦
- レーン戦
- ガンク
- ローム
- ポーク
- エンゲージ
- 視界
- CC

必要であれば、初回公開前に以下を追加候補とする。

- オブジェクト
- プッシュ
- ウェーブ
- バースト
- キャリー
- スケール

### 4.3 ロール解説

以下を必須とする。

- Top
- Jungle
- Mid
- ADC
- Support
- 各ロールの役割と見どころ

### 4.4 オブジェクト解説

以下を必須とする。

- タワー
- ドラゴン
- バロン
- ヘラルド
- インヒビター
- オブジェクトを取る意味

### 4.5 チャンピオン一覧

以下を初回公開時の要件とする。

- チャンピオン一覧ページを用意する
- 各チャンピオンに最低限の要約文を載せる
- 一覧上でロールが分かるようにする

一覧に載せる最小情報:

- チャンピオン名
- 画像
- 主なロール
- ひとことで言うと

### 4.6 一部チャンピオン詳細

初回公開時は、`10体前後` を目安に個別ページを作成する。  
選定基準は以下を優先する。

- 配信や大会で比較的見かけやすい
- 役割の違いが分かりやすい
- 初心者が見て特徴を覚えやすい

各チャンピオン個別ページの必須項目:

- ひとことで言うと
- どのロールで使われるか
- 得意なこと
- 苦手なこと
- 観戦で注目するポイント
- スキルのやさしい解説
- おすすめルーン
- よくあるアイテム
- 初心者向けメモ

### 4.7 最新パッチ要約

初回公開時は、`最新パッチのやさしい要約を1本` 用意する。

最低限含める内容:

- 今回のパッチの全体像
- 初心者に関係ある変更
- 観戦で見え方が変わるポイント
- 主要なチャンピオン変更
- 主要なアイテム変更

## 5. MVPで後回しにするもの

以下は MVP の対象外とする。

- アイテム入門の本格実装
- チャンピオン検索や高度な絞り込み
- 用語検索機能
- 過去パッチの大量アーカイブ
- 全チャンピオン個別ページ
- パッチ差分の自動生成
- ルーンやアイテムの自動最適化更新

## 6. 初回公開時の実装優先順位

1. はじめて見る人向け
2. 用語集
3. ロール解説
4. オブジェクト解説
5. チャンピオン一覧
6. 一部チャンピオン詳細
7. 最新パッチ要約

## 7. 備考

- チャンピオン詳細の対象数は、実装負荷に応じて `5体` まで縮小してもよい
- 逆に余力があれば、`10〜15体` 程度まで拡張してよい
- 初回公開では、`広く浅く` よりも `少なくても分かりやすい` ことを優先する
